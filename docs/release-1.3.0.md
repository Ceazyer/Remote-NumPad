# Remote NumPad 1.3.0 更新与安装说明

## Windows 原生 GUI 与托盘

- 使用图形面板代替命令行，启动即打开面板并尝试按上次成功端口接收。
- 可选择局域网网卡、修改端口、刷新地址、复制连接地址、打开网页、查看二维码、查找建议端口、启动/停止/重启接收。
- 端口被占用时面板仍可打开；新端口启动失败会尝试恢复原接收端，地址与二维码只跟随实际生效状态，不结束占端口的其他程序。
- 更换网卡或 IP 后刷新二维码。停止接收后二维码不再显示为可用。
- 双击托盘打开主面板；右键可控制接收、复制/打开地址、查看二维码/日志、修改端口、查看关于、退出。
- 关闭窗口或最小化会隐藏到托盘；“退出程序”才真正停止接收、释放端口。重复运行 EXE 只打开已有面板，不启动第二个服务。
- 录入前必须切回 Excel/WPS。接收端不置顶，不自动修改防火墙或设置开机启动。

## Android 本机扫码与轻触反馈

- 在连接设置中选择“扫描电脑连接二维码”。首次扫码才申请相机权限；拒绝后仍能手动连接。
- 同一二维码用于浏览器打开与 APK 识别，格式为 `http://私有IPv4:端口/?app=remotenumpad&v=1`。
- 只接受固定格式、私有 IPv4 和有效端口；识别后先显示确认，协议握手成功才保存新设置。扫码不是身份认证。
- 有待发送项时必须明确选择返回处理、清空后连接，或确认仍为同一电脑并保留队列；不会自动把旧输入转移给另一台电脑。
- 端口更改后需要重新扫码或手动修改手机端口；本版不做无感迁移。
- “按键轻触反馈”默认关闭、遵循系统触感设置；仅成功加入持久队列后触发，不等待网络 ACK，不加去抖。队列满、非法输入不会触发成功反馈。
- 震动不是 Excel 录入成功证明；高频震动可能被设备合并。扫码画面只在本机处理，不保存、不上传。进入/离开扫描页会打开/释放相机。
- 原有两页软拟物黑白主题、向心五边形方向键、四宫格与数字布局保持不变。

## 正式包与升级

Windows：解压 Windows ZIP 后运行 `RemoteNumPad.exe`。配置存到本机用户目录，不需要额外安装 .NET。Windows 包没有商业 Authenticode 证书，可能显示未知发布者。

Android：安装 `RemoteNumPad-1.3.0-release.apk`。它使用新的正式发布签名，旧调试版通常需自行卸载后才能安装；卸载前处理完队列并记下连接设置。后续正式版本必须保留同一签名。密钥备份见 [发布签名说明](release-signing.md)。

网络仍采用明文局域网 WebSocket，二维码不是配对认证；不要暴露到公网。日志只记录接收状态、端口与错误，不记录按键内容或剪贴板数据。

## 验证范围

- Windows 端口冲突/切换/失败回退、嵌入网页、设置保存、GUI 按钮尺寸、二维码刷新、关闭到托盘和停止状态。
- Android 队列与 QR 格式单元测试、模拟器数字/方向各 100 次合成触摸、成功入队反馈回调、电脑生成二维码实际解码、正式包安装与扫码权限/页面。
- 发布 APK 经过签名验证、调试标记检查和 R8 压缩。相机真实对焦速度、实体震动手感、Excel/WPS 接收结果仍需用户真机验收。
