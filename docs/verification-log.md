## 记录与复用

按 [开发规则](development-rules.md) 选择检查。每次仅记录标识、源码/测试/配置/依赖状态、环境、实际命令/步骤、结果/局限、引用或失效原因；未执行写“未执行”，不要写通过。

```text
标识 / 修改范围：
源码/测试状态：提交 + 相关差异或指纹；配置/依赖有无变化
环境：运行时、系统/设备、执行目录，不含私人信息
检查：实际命令/步骤、安全过滤器与模拟器目标
结果与边界：通过/失败/未执行；不能证明什么
证据复用：引用条目；或失效/补测原因
```

同输入/范围的通过检查可引用；实时焦点/连接/硬件与新包不能借此跳过。历史摘要缺完整指纹/命令时不作直接复用凭据。
